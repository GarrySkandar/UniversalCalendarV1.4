CORE

Planetary / Temporal

Instant、JDN/UTC、Planet、Rotation、Orbit；地球是当前正式实现，火星已用实验太阳时验证扩展接口。

CORE

Location

经纬度、海拔、行政时区、地区 Profile。地图选点属于这里，而不是国家层。

ENGINE

Astronomy

太阳、月亮、朔望、节气、日出日落；星占或历法可以消费这些结果，但不能反向污染物理层。

ENGINE

Calendar

Solar/Lunar/Lunisolar Rules 与非标准 Representation 的 Special Plugins。

CONTEXT

Civilization

Era、Religion、Country、History 和权威年度数据是并列语义层。

INTERPRET

Time Interpretation

中国黄历、Panchanga、Pawukon、择日、星占、皇极经世/Yuga 等进入统一解释插件层。

OPTIONAL

Personal Context

八字、个人占星等需要 Person + Birth TemporalPoint，和日期自身属性严格分离。

GOVERNANCE

Capability Status

Core / Full / Versioned / External / Historical / Experimental / Planned，禁止把预留接口写成“已支持”。
